
# Transformer Efficiency Calculator ⚡

## About
A beginner-level EEE project using Python
to calculate transformer efficiency and
power losses.

## Features
- Calculates efficiency
- Calculates power losses
- Accepts user input
- Displays calculated results

## Formula
Efficiency = (Output Power / Input Power) × 100

Power Loss = Input Power - Output Power

## Technologies Used
- Python
- Electrical Engineering Fundamentals

## Learning Outcomes
- Understanding transformer efficiency
- Understanding power losses
- Applying Python programming in EEE
